# Secure Forms 
A small project where, students are able to Sign-in, or Sign-up if you arent a user. Once a form or assignment is submitted, one can double check to see if it is the right one, lists all previous submitted forms. 

## What it does
Sign up and Sign in
Upload a form or a file with its title and description
See the submission in a two column page: description on the right and list on the left
Uploading needs an account and Home and Back work even when signed out.


**Tech**
Javascript
SQL
CSS
HTML

## Getting started
Clone the repository or Download it.

## Requirements
Node.js 18 or newer

# Run it 
npm install
node savarr.js

Then open, http://localhost:3000/User/Fpage.html.
Do not use a live server for this project, it only servers static files so majority will not work
